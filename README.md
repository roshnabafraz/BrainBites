# BrainBite  
**Knowledge, one tap at a time.**

BrainBite is a lightweight Android app built entirely with **Jetpack Compose**. It delivers fun, bite-sized facts on every tap, keeping learning simple, focused, and enjoyable.

## 🚀 Features
- Minimal and distraction-free UI using **Jetpack Compose**
- One-tap fact generation for quick micro-learning
- Smooth animations and clean layout
- Easy-to-extend JSON-based data source
- MVVM structure with modern Android best practices

## 🛠️ Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **MVVM**
- **StateFlow**
- **Retrofit-ready architecture**
- **Local JSON data**
- **Material 3**
